# Lezzet Rehberi - BLM2537 Ağ Tabanlı Programlamaya Giriş Dönem Projesi

Bu proje, BLM2537 dersi kapsamında geliştirilen yemek tarifleri ve besin değerleri rehberi web sitesidir.

## Kullanılan Teknolojiler
- HTML5 (Semantik etiketler, tablolar, formlar)
- CSS3 (Kutu Modeli, Flexbox mimarisi)

## Projeyi Çalıştırma Adımları
1. Proje dosyalarını bilgisayarınıza indirin veya `git clone` ile çekin.
2. Klasörü **Visual Studio Code** ile açın.
3. VS Code üzerindeki **Live Server** eklentisini kullanarak `index.html` dosyasını tarayıcıda başlatın (Sağ tık -> *Open with Live Server*).
